💱 Convert Money

Um conversor de moedas desenvolvido durante meus estudos de programação no DevClub, com o objetivo de praticar conceitos de desenvolvimento web e aprofundar meus conhecimentos em JavaScript.

O projeto permite converter valores entre quatro moedas: Real Brasileiro, Dólar Americano, Euro e Libra Esterlina, utilizando cotações obtidas através de uma API externa.

🖥️ Demonstração do projeto



🚀 Tecnologias utilizadas

HTML5: estruturação dos elementos da página.

CSS3: estilização e organização do layout.

JavaScript: lógica de conversão e manipulação do DOM.

API Frankfurter: consulta das cotações das moedas.

💰 Funcionalidades

Conversão entre Real, Dólar, Euro e Libra.

Consulta de cotações através de API.

Seleção da moeda de origem e destino.

Atualização das imagens e nomes das moedas selecionadas.

Formatação automática dos valores monetários.

📚 Conhecimentos praticados

Durante o desenvolvimento deste projeto, pratiquei:

Manipulação do DOM com querySelector e getElementById.

Criação e utilização de funções JavaScript.

Eventos com addEventListener.

Consumo de APIs utilizando fetch.

Funções assíncronas com async/await.

Tratamento de erros com try/catch.

Formatação monetária com Intl.NumberFormat.

🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em programação, colocando em prática os conhecimentos adquiridos em desenvolvimento web e evoluindo minhas habilidades com JavaScript.
